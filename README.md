# Cloud OCR & Sentiment Analyzer 🚀☁️

A sleek web application built with **Streamlit** that extracts text from uploaded images using Cloud OCR and performs automated sentiment analysis using **TextBlob**.

---

## ✨ Features
* **Cloud OCR Integration:** Extract text accurately from various image formats (PNG, JPG, JPEG).
* **Sentiment Analysis:** Analyze the emotional tone of the extracted text instantly.
* **Security Best Practices:** API keys and sensitive credentials are safely isolated using Streamlit Secrets (`secrets.toml`) and excluded via `.gitignore`.

---

## 🛠️ Tech Stack
* **Python**
* **Streamlit**
* **PIL (Pillow)**
* **TextBlob**
* **Requests**
